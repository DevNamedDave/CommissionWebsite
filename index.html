01 // About

What I do

I’m most useful when a project already has a direction and needs someone to actually build the systems, fix what is broken, or keep development organized. I prefer practical code and clear scope over making things more complicated than they need to be.

Gameplay scripting

Progression, shops, rewards, data, monetization, UI logic, round systems, and general gameplay features.

Bug fixing & polish

Finishing incomplete systems, cleaning up rough behavior, and getting projects closer to a release-ready state.

Project management

Scope, priorities, milestones, task planning, and keeping a project focused on what actually needs to ship.

Existing codebases

I can step into an existing project, figure out how it is put together, and work within the structure already there.
